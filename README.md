# natepogue83.github.io

Source for my portfolio at https://natepogue83.github.io.

It's a plain static site with no build step. `work.js` holds all the content, `render.js` draws the page from it, and `style.css` styles it. `research/religion-themes/` holds the full religion-themes report and its errata, which the site links to.

The experiment code and data are in https://github.com/natepogue83/isnad, and the Slay the Spire 2 AI is in https://github.com/natepogue83/sts2-ai.

The site was built by AI agents (Claude) working under my direction.
